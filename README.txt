CHURCH MUSIC IMPORTER - FRIENDLIER REVIEW UPDATE

What changed:
- Existing files are still checked, but are hidden from the review list.
- The opening screen gives one simple summary such as:
    21 files already in the library - hidden from review
    NEEDS YOUR ATTENTION: 4
- Only new, changed, or uncertain files are shown for review.
- Each actionable file gets its own clean screen.
- The importer waits for Enter before moving to the next actionable file.
- Matching, R2 uploading, library writing, and duplicate-type handling remain fundamentally the same.
- GitHub publishing remains built in and stages only js/music-library.js.

INSTALL
1. Close the importer if it is running.
2. Extract this ZIP into the root of your existing church-music-library project.
3. Allow Windows to replace the existing files when asked.
4. Launch Church Music Importer.bat normally.

This update does not include or replace your .env, credentials, music library, or R2 configuration.
