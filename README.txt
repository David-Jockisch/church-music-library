CHURCH MUSIC LIBRARY — MULTIPLE SHEET MUSIC UPDATE

WHAT THIS ADDS
- More than one PDF can be stored on the same song.
- Importer recognizes common sheet suffixes and matches them to the base song.
- Practice mode asks which sheet to use when a song has multiple PDFs.
- It then asks which audio track to use when multiple tracks exist.
- Songs with only one PDF keep the simple existing behavior.
- Keeps the quieter v3 importer: existing files are checked but hidden from review.
- Keeps Save / Commit / Push from inside the importer for music-library updates.

RECOMMENDED PDF FILENAMES
  Build My Life - Bass.pdf
  Build My Life - Guitar.pdf
  Build My Life - Guitar Capo 2.pdf
  Build My Life - Rhythm Guitar Capo 3.pdf
  Build My Life - Chords.pdf
  Build My Life - Lead Sheet.pdf

The suffix is removed only for song matching. The original filename is retained in R2.

INSTALL
1. Extract this ZIP into the ROOT of your existing church-music-library project.
2. Allow Windows to replace the matching files.
3. Run "Apply Update & Push.bat" ONCE so the app update is committed and pushed.
4. After that, use "Church Music Importer.bat" normally.

IMPORTANT
Your .env, R2 credentials, existing music-library.js, and existing media are NOT included
in this update ZIP and are not overwritten.
